# AlgoArena - Online Coding Compiler

AlgoArena is a web-based online coding platform that allows users to write, edit, and execute code directly in the browser.  
It provides an interactive coding environment similar to modern IDEs with a user-friendly interface.

---

## 🚀 Features

- 🧑‍💻 Online code editor using **Monaco Editor (VS Code Editor)**
- 🔐 User authentication (Login / Signup pages)
- 🌐 Web-based coding environment
- ⚡ Fast React-based frontend
- 🔗 API communication using Axios
- 📦 Deployable using GitHub Pages

---

## 🛠 Technologies Used

### Frontend
- HTML5

- Monaco Editor

### Backend / Server
- Node.js

- Axios

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/AlgoArena.git
cd AlgoArena

2️⃣ Install Dependencies
cd online_compiler
npm install
3️⃣ Start the Development Server
npm start

The application will start on:

http://localhost:3000

🖥 Usage

Open the application in your browser.

Login or create a new account.

Write your code in the online editor.

Run and test your code directly in the browser.

📦 Build for Production
npm run build
🚀 Deployment

This project can be deployed easily using GitHub Pages

npm run deploy
